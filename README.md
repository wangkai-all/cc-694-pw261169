# 公路观测里程归仓工具

把巡检记录里的**里程牌读数**换算成某版路线上的**连续位置**（归仓），并能从连续位置**反查原读数**。
纯示意线 + 表格，不接地图服务。原始读数永不改写，换算结果与下游公里事实随路线版本演进。

## 领域规则

**分段映射**：每个路线版本由若干有序区段组成。区段给出 `读数起 → 读数讫`（可逆向），
连续位置从 0 起逐段等距累加：`链位 = 链位起 + |读数 - 读数起|`。段间链位连续，断链全部体现在读数上：

- **短链（缺号）**：下一段读数起 > 上一段读数讫，跳过的读数不存在 → 落在其中的记录进**异常区**。
- **长链（重号）**：下一段读数起 < 上一段读数讫，重叠读数对应两个位置 → 记录保留**多个候选**，
  由“区段标记”或人工消歧，**绝不默认取第一个**。
- **逆向读数**：区段读数沿链位方向递减（`读数讫 < 读数起`），段内反向等距映射。

**边界包含（全线统一）**：每个区段拥有闭区间读数。同一读数经相邻段算得**同一链位**时去重，
只入仓一次（连续接缝不重复计）；算得**不同链位**时各算一个候选。公里区间分箱左闭右开 `[n, n+1)`。

**版本与订正**：按记录“发生日期”选版（`生效日期 ≤ 发生日期` 的最新已发布版，生效当日即用新版）。
历史订正产生新版本（可与被订正版同一生效日期，发布后旧版置“已取代”）。发布后受影响记录重算：
旧公里区间事实**撤回**（保留台账），按新位置**重建**；人工消歧结果在版本未变时保持稳定，跨版本需重新确认。

### V1（2026-01-01 生效）：全线直线 读数 0→20，链位 0→20

### V2（2026-06-01 生效）：短链 + 长链

| 区段 | 读数 | 链位 |
|---|---|---|
| K0-K10主线 | 0→10 | 0→10 |
| — 短链：读数 (10,12) 缺号 — | | |
| 短链后段 | 12→15 | 10→13 |
| — 长链：读数 [13,15] 重号 — | | |
| 长链重复段 | 13→16 | 13→16 |
| K16-K20主线 | 16→20 | 16→20 |

正向（读数→链位）：

| 读数 | 结果 | 说明 |
|---|---|---|
| 10 | 10 | 短链断点左侧，存在 |
| 11 | **异常** | 缺号区，不存在 |
| 12 | 10 | 短链断点右侧，与读数 10 同链位 |
| 14 | **候选 12 / 14** | 长链重号，保留两个候选 |
| 14 + 标记「长链重复段」 | 14 | 区段标记消歧 |
| 14 + 标记「短链后段」 | 12 | 同上 |
| 14 + 标记「不存在段」 | **异常** | 标记与候选矛盾 |
| 15 | 候选 13 / 15 | 重号区边缘 |
| 16 | 16 | 连续接缝：两段算得同一链位，**去重只入仓一次** |
| 21 | **异常** | 超界 |

反向（链位→读数）：链位 10 → **读数 10 与 12**（短链断点双读数）；链位 12 → 14；链位 14 → 14；
链位 16 → 16（接缝去重，只报一个）；链位 21 → 异常。

|---|---|---|
| K0-K16 | 0→16 | 0→16 |

读数 16 → **候选 16 / 20**（正向段末端与逆向段末端重号）；反查链位 16 → 读数 16 与 20。

### 版本交接日期（V1→V2，2026-06-01 交接）

| 发生日期 | 读数 | 版本 | 链位 | 公里区间 |
|---|---|---|---|---|
| 2026-05-31 | 12.6 | V1 | 12.6 | K12 |

### 撤回再重建

V2 发布前导入 6 月记录（读数 12.6）→ 按 V1 入仓链位 12.6、事实 K12；
发布 V2（2026-06-01 生效）→ 该记录重算为链位 10.6，**K12 撤回、K10 重建**，原始读数 12.6 不动。
歧义记录在消歧前不产生公里事实；消歧（或改判）时按选定位置建（撤旧建新）。

以上数值全部由 `tests/` 中 24 条用例逐一核对。

## 运行

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python seed.py                 # 可选：写入 G108 基准数据
.venv/bin/uvicorn app:app --port 8765    # 打开 http://127.0.0.1:8765
.venv/bin/python -m pytest tests/ -q     # 手算基准回归
```

## 页面

- **版本与断链**：版本列表、断链示意图（短链红虚线 / 长链黄虚线 / 逆向标注）、区段编辑、
  预览受影响记录、发布。
- **数据导入**：粘贴 CSV：`路线,方向,里程牌读数,发生日期[,区段标记]`（首行可为表头）。
- **记录与歧义**：按状态过滤；待消歧记录选择候选位置入仓；异常记录给出原因。
- **反查**：选版本输入连续位置，给出全部对应读数（短链断点会给出两个）。
- **公里事实**：当前有效区间汇总 + 含撤回记录的完整台账。

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/versions?route=` | 版本及区段 |
| POST | `/api/versions` | 新建草稿（`copy_from` 可复制既有版） |
| PUT | `/api/versions/{id}/segments` | 整体替换草稿区段（链位自动累加） |
| GET | `/api/versions/{id}/preview` | 预览发布影响 |
| POST | `/api/versions/{id}/publish` | 发布：重算受影响记录，事实撤回重建 |
| POST | `/api/records/import` | 导入 CSV |
| GET | `/api/records?route=&status=` | 记录与候选 |
| POST | `/api/records/{id}/resolve` | 人工消歧入仓 |
| GET | `/api/reverse?version_id=&chain=` | 反查读数 |
| GET | `/api/facts?route=` | 公里事实台账与汇总 |
